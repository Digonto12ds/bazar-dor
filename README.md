# 🛒 বাজার দর (BazarDor)

### আজকের বাজারের দাম এক নজরে

BazarDor is a responsive web application that helps users explore daily prices of essential products in Bangladesh. Users can compare prices, check market-wise details, and track which products have increased or decreased in price.

The goal of BazarDor is to make everyday market price information easier to access through a simple, user-friendly interface.

---

## ✨ Key Features

- 📊 **Daily Price Tracking** — View today's prices of essential products and their price changes.
- 📈 **Price Increase & Decrease** — Explore products with the highest price increases and decreases.
- 🛍️ **Product Details** — View detailed product information, including average, minimum, and maximum prices.
- 🏪 **Market-Wise Price Comparison** — Compare product prices across different markets.
- 🔐 **User Authentication** — Sign up, sign in, and access protected pages.

---

## 🛠️ Technologies Used

- **Next.js** — React framework for building the application.
- **React** — Component-based user interface.
- **TypeScript** — Type safety and better code maintainability.
- **Tailwind CSS** — Responsive styling and layout.
- **Better Auth** — User authentication.
- **MongoDB** — Database for authentication-related data.
- **BazarDor API** — Product categories, prices, and market information.

---

## 📱 Responsive Design

BazarDor is designed to work across different screen sizes:

- 📱 Mobile phones
- 📲 Tablets
- 💻 Desktop computers

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Digonto12ds/bazar-dor.git
```

### 2. Navigate to the project folder

```bash
cd bazar-dor
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the project root and add the required environment variables:

```env
MONGODB_URL=your_mongodb_connection_string
BETTER_AUTH_SECRET=your_better_auth_secret
BETTER_AUTH_URL=http://localhost:3000
```

Replace the example values with your actual credentials. Never commit secrets to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
